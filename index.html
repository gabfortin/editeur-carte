Importez un fichier CSV de lieux, ou partez d'une carte vide et ajoutez des points et des lignes.

Format du fichier

Une ligne par lieu. Colonnes reconnues (export Mapme compatible) :

  • name : nom du lieu
  • latitude, longitude : position
  • description : texte, HTML simple accepté
  • categories : séparées par ;
  • address, actionText, actionUrl
  • geometry : une ligne (tracé) en WKT, ex. LINESTRING (-73.58 45.52, -73.57 45.53)

Les autres colonnes sont gardées telles quelles et ressortent à l'export CSV.

On peut aussi rouvrir une carte exportée en HTML ou un fichier de projet (.json).

            Éditeur de carte

            Cet outil sert à monter une carte de lieux à partir d'un fichier CSV (par exemple un export Mapme), à la corriger et à la publier en une page HTML autonome, à intégrer dans un autre site.

            Vos données restent sur votre appareil. Le fichier est lu par votre navigateur et les cartes sont enregistrées dans ce navigateur seulement. Rien n'est envoyé à un serveur.

            Comment faire

            Déplacer un point ou une ligne

            Sélectionnez le lieu (sur la carte ou dans la liste), puis glissez le point, ou les sommets de la ligne. Clic droit sur un sommet pour le retirer.

            Lieux « à vérifier »

            Ce sont les lignes du fichier sans position, ou placées à plus de 100 km des autres (souvent une adresse mal géocodée). Ils restent dans le CSV exporté ; ceux sans position n'apparaissent pas sur la carte publiée.

            Publier la carte

            Exporter → Télécharger la page HTML. Mettez le fichier en ligne (GitHub Pages, votre site), puis intégrez-le avec le code d'iframe fourni. Ouverte directement depuis votre disque, la page peut afficher un fond de carte bloqué : c'est une règle d'OpenStreetMap, une fois en ligne tout s'affiche.
